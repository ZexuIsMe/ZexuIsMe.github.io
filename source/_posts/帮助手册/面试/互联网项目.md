## （必知必会） Swagger 

【描述】 一个开源框架，主要用于设计、构建、记录和使用 `RESTful Web` 服务的工具集合

【组成部分】 
① Swagger UI 一个前端界面，用于显示 API 文档，并提供交互式功能，允许开发者测试 API 请求和查看响应
② Swagger Editor 一个在线编辑器，用于编写和编辑符合 OpenAPI 规范的API文档
③ Swagger Codegen 一个工具，用于根据 API 文档生成客户端 SDK、服务端代码和API文档
④ Swagger Hub 一个平台，用于团队协作和管理API文档
