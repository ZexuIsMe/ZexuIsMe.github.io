## 等价类：三角形

一个程序输入3个整数，把这三个数值看作一个三角形的3条边的长度值，这个程序要打印出信息；说明这个三角形是普通的，是等腰的，还是等边的，或是提示输入有误：不是三角形

| 有效等价类        | 编号 |
|--------------|----|
| 任意两边之和 > 第三边 | E1 |
| 任意两边相等       | E2 |
| 任意三边相等       | E3 |

| 无效等价类                | 编号 |
|----------------------|----|
| 任意两边之和小于第三边          | A1 |
| 任意两边之和等于第三边          | A2 |
| 负数                   | A3 |
| 小数                   | A4 |
| 非数字字符（字母、汉字、特殊字符，全角） | A5 |
| 0                    | A6 |

| 等价类类型 | 测试数据    | 预期结果  | 覆盖的等价类 |
|-------|---------|-------|--------|
| 有效    | 3,4,5   | 普通三角形 | E1     |
| 有效    | 3,3,5   | 等腰三角形 | E1，E2  |
| 有效    | 3,3,3   | 等边三角形 | E1，E3  |
| 无效    | 1,1,3   | 不是三角形 | A1     |
| 无效    | 1,2,3   | 不是三角形 | A2     |
| 无效    | 1,-2,3  | 不是三角形 | A3     |
| 无效    | 1,2.0,3 | 不是三角形 | A4     |
| 无效    | 1,1%,3  | 不是三角形 | A5     |
| 无效    | 1,0,3   | 不是三角形 | A6     |

细节优化
- F4：`1,2.0,3`可以更改为`1,2.4,3`更能体现非证书特征，因为 2.0 可能会被认为是整数

## 等价类：黄历

万年历查询软件，要求用户输入以年月日表示的日期，然后系统会换算出该日期的农历表示法及相关黄历信息，假设日期限定在1900年1月1日~2049年12月31日，并规定日期由8位数字字符组成，前4位表示年，中间2位表示月，最后两位表示日期。其中4、6、9、11月只有30天，平年的2月份只有28天，闰年的2月份有29天。

| 有效等价类              | 编号 |
|--------------------|----|
| 年：[1900, 2049]     | E1 |
| 字符长度：8位数字          | E2 |
| 小月：<= 30           | E3 |
| 平年2月：<=28          | E4 |
| 润年2月：<=29          | E5 |
| 大月：<=31            | E6 |
| 日期范围：>= 1          | E7 |
| 月份范围：1 <= 月份 <= 12 | E8 |

| 无效等价类                   | 编号  |
|-------------------------|-----|
| 字符长度 < 8                | A1  |
| 字符长度 > 8 位              | A2  |
| 年份 < 1900               | A3  |
| 年份 > 2049               | A4  |
| 年份：非数字字符（特殊字符、汉字、字母、全角） | A5  |
| 月份 > 12                 | A6  |
| 月份 < 1                  | A7  |
| 月份：非数字字符（特殊字符、汉字、字母、全角） | A8  |
| 大月天数 > 31天              | A9  |
| 天数 < 1天                 | A10 |
| 小月天数 > 30天              | A11 |
| 天数：非数字字符（特殊字符、汉字、字母、全角） | A12 |
| 平年2月天数 > 28 天           | A13 |
| 闰年2月天数 > 29 天           | A14 |

这里的年份、月份、天数的非数字字符，如果是连续的输入，那么就不能合并，如果是分开的三个输入框，那么可以合并。

但题目没有说明白，所以暂时按连续输入的情况而定，故，A5，A8,A12均要拆分为4个用例
