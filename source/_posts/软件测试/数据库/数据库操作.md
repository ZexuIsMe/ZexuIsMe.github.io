- DQL（数据**查询**语言）：查询数据的数据，是学习的重点和难点；代表性关键字【select】
- DML（数据**修改**语言）：改变数据库的数据，次重点；代表性关键字【insert、update、delete】
- DDL（数据**定义**语言）：用于定义数据的结构，次次重点；代表性关键字【create、alter、drop】
- DCL（数据**控制**语言）：用于控制访问权限，通常由DBA（数据库管理员 Database Administrator）来操作；代表性关键字【grant、revoke】

## 数据类型：数字

- int：`int(11)`
  - type: 整型
  - 11：表示 int 类型最大位数，其取值区间为 [1, 11]
  - 如果位数不够，如 100，则不足的部分会由0填充：00000000100

- float：`float(m,d)`
  - type: 单精度浮点型
  - m：表示长度或者位数
  - d：表示小数位数（小数位数是算在长度内的）
  - Eg: `float(6,2)`：表示该浮点数最大长度位6，且有两位小数，整数长度为 m-d, 即 4 位
  - 若长度超出6，如 12345，则不会被允许添加

- double：`double(m,d)`
  - type: 双精度浮点型
  - m、d 同 float 一样
  - Q：单精度与双精度有什么区别？

    能定义的长度不同，单精度为4个字节（7位有效数），双精度为8个字节（16位有效数）

- decimal: `decimal(m,d)`
  - type: 定点型
  - m、d 同 float 一样
  - Q：浮点型与定点型的区别？

    浮点型是<mark>近似值</mark>数据类型，存在误差，如 10/3 ≈ 3.33333 在数据库中可能是 3.33335。

    **定点型以字符串的形式存储数据，解决了浮点型带来的误差问题**。

    故，如果对数据的完整度十分敏感，那么采用定点型数据类型是合适的。

## 数据类型：字符

- char: `char(m)`
  - type: 字符串
  - m：表示字符串的长度
  - 一种固定了长度的，如果字符不够，则会用空格替代的字符串数据类型
  - 如一个长度为5的 char 字段，要写入 '汉字' > '汉字xxx'（x 在这里表示空格占位）
  - 同 int 一样，若超出长度，则无法写入

- varchar: `varchar(m)`
  - type: 字符串
  - m：表示字符串的长度
  - 不固定长度的字符串数据类型
  - 如一个长度为5的 varchar 字段，要写入 '汉字' > '汉字2'；其中2表示该字符的长度
  - 同 int 一样，若超出长度，则无法写入
  - Q：char 与 varchar 的区别？

    char是固定长度的，可以有更快的读取速度，如固定长度的身份证之类的
    varchar 是不固定长度的，相对于 char 而言，节约开销，比如名字，就适合用 varchar

- enmu: `enmu('1', '2', ...)`
  - type: 枚举型
  - 设置字段的取值范围

### 外键

语法：FOREIGN KEY(当前表即将成为外键的字段名) REFERENCES 外键目标数据表(目标数据表的主键字段名)

- FOREIGN：foreign
- REFERENCES：references

```sql
CREATE TABLE A (
    c1 INT PRIMARY KEY,
    c2 VARCHAR(20)
);

CREATE TABLE B (
    cc1 INT,
    cc2 VARCHAR(5),
    cc3 INT,
    FOREIGN KEY(cc3) REFERENCES A(c1)
);
```

注意，如果删除表，那么应该先删除数据表B，再删除数据表A

一般情况下不太会用外键，因为外键会影响SQL运行速度，若用户量没那么多的，可以考虑


### limit

- `limit N` 返回 N 条记录，默认为前 N 条；
- `offset M`：跳过 M 条记录，默认为 0 ，单独使用不起作用；
- `limit N,M`：相当于 `limit M offset N`，从第 N 条记录开始，返回 M 条记录；

```sql
/*---返回指定数量记录：limit---------------------------------------*/
## 取前两条记录，只要设备ID
select device_id from user_profile limit 2;
```

**Q：写语句时常遇到“24岁以上”这样的条件，到底是大于等于还是只大于呢？**

A：是只大于的，如果是大于等于，应该是“24岁及以上”

### IS NULL、IS NOT NULL

语法：`目标 IS NULL`

`NULL`值无法通过常规的逻辑运算符判断，也就是无法使用如 `age=NULL` 这样的写法;

那么该如何判断空值呢？

Eg: 现在运营想要对用户的年龄分布开展分析，在分析时想要剔除没有获取到年龄的用户，请你取出所有年龄值不为空的用户的设备ID，性别，年龄，学校的信息。

```sql
SELECT device_id,gender,age,university
    FROM user_profile
    WHERE age IS NOT NULL;
```

**过滤空值的三种方法**：
(1) Where 列名 is not null
(2) Where 列名 != 'null'
(3) Where 列名 <> 'null'

### LIKE

通常和通配符`%`、`_`配合使用，做模糊查询

Eg：现在运营想查看所有大学中带有"北京"的用户的信息(device_id,age,university)，请你取出相应数据。

```sql
SELECT device_id,	age,	university
FROM user_profile
WHERE
    university LIKE '%北京%'
# 描述的是带有“北京”二字，所以不排除存在“XX北京”的文本
```

- 以某某开头：`LIKE X%`
- 以某某结尾：`LIKE %X`
- 包含某某：`LIKE %X%`
- 第二个字符是e的：`LIKE _e%`
- 不包含某某：`NOT LIKE %XX%`

## 通配符

- %：匹配多个字符；`北京%`表示北京大学，北京医院，北京车站等等
- _：匹配一个字符；如上即可明白
- 正则：https://www.runoob.com/sql/sql-wildcards.html
  - `WHERE name REGEXP '^[GFs]'`: 名字以 G、F、s开头的
  - `WHERE name REGEXP '^[A-H]'`: 名字在 A~H 这个区间内开头的
  - `WHERE name REGEXP '^[^A-H]'`: 不以 A 到 H 字母开头

> 通配符是通配符，正则是正则，不要混淆了。
> 比如菜鸟教程底部的笔记，前两篇可以看，后面的就不要看了，只会让你越看越懵逼
