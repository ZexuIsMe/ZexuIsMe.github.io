## 路径类

> JavaScript：字符串编码

【encodeURI】 对整个字符串进行编码，但不包含结构字符（`/`、`?`、`&`、`=`）

    encodeURI('https://example.com/path/文件名?param=值&key=1')
    ## "https://example.com/path/%E6%96%87%E4%BB%B6%E5%90%8D?param=%E5%80%BC&key=1"

以【decodeURI】解码【encodeURI】

【encodeURIComponent】 对整个字符串进行编码，包括结构字符，如`/`、`?`、`&`、`=`

    encodeURIComponent('文件名/包含?特殊&字符')
    ## "%E6%96%87%E4%BB%B6%E5%90%8D%2F%E5%8C%96%E5%90%AB%3F%E7%89%B9%E6%AE%8A%26%E5%AD%97%E7%AC%A6"

以【decodeURIComponent】解码【encodeURIComponent】

## 关于脚本攻击

> 会触发的脚本攻击的渲染方式

```javascript
// 解码后包含恶意脚本
const decoded = "<script>stealData()</script>";
// 直接插入DOM会执行脚本
element.innerHTML = decoded; 
```

> 如何避免？

【方案一】
避免使用`innerHTML`、`v-html`（Vue）、`dangerouslySetInnerHTML`（React）等直接插入 `HTML` 的 `API`，优先使用文本渲染：
```javascript
// 安全方式：插入文本（浏览器会自动转义HTML）
document.getElementById("content").textContent = decoded;
```

【方案二】解码后进行过滤 / 转义

使用库（如DOMPurify）或自定义函数过滤恶意标签：

```javascript
import DOMPurify from 'dompurify';

// 解码后先过滤再渲染
const safeHtml = DOMPurify.sanitize(decoded);
document.getElementById("content").innerHTML = safeHtml;
```
