## Step 5 : 渲染列表添加删除按钮
要求：内容为删除，高度为20，字体大小为10
```text
//用列表容器显示员工列表
List({ space: 20 }) {
  ForEach(this.employees, (item, index) => {
    ListItem() {
      Row() {
        Text((index+1)+" ").fontSize(18).width('10%')
        Text(item.name).fontSize(18).width('25%')
        Text(`￥${item.salary}`).fontSize(18).fontColor(Color.Gray).padding({right:10}).width('20%')
        Text(item.dept).fontSize(18).width('30%')
        // 添加删除按钮
        Button("删除").height(20).fontSize(10)
      }
    }
  }, (item) => JSON.stringify(item))
}
```
## Step 6: 通过ID删除员工信息

```text
  async deleteEmployeeById(id: number) {
    try {
      this.rdbStore.executeSql("delete from employees where id=?", [id])
    } catch (err) {
      console.log("删除失败", JSON.stringify(err));
    }
  }
```

方法写好后，对删除按钮进行函数绑定，删除成功后查询所有数据

```text
Button("删除").height(20).fontSize(10).onClick(async () => {
```
