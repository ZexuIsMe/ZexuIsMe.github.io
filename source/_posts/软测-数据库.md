## 操作：数据库

<dl>
    <dt>添加数据库</dt>
    <dd>语法：<code>create database 数据库库名;</code></dd>
</dl>

---

<dl>
    <dt>删除数据库</dt>
    <dd>语法：<code>drop database 数据库库名;</code></dd>
</dl>

---

<dl>
    <dt>查看数据库</dt>
    <dd>语法：<code>show databases;</code></dd>
</dl>

---

<dl>
    <dt>使用数据库</dt>
    <dd>语法：<code>use 数据库库名;</code></dd>
</dl>

## 操作：数据表
<dl>
    <dt>添加一个表</dt>
    <dd>语法：<code>create table 表名(字段1 数据类型, 字段2 数据类型);</code></dd>
    <dd>Eg: <code>create table student(id int, sname varchar(20));</code></dd>
</dl>

---

<dl>
    <dt>删除数据表</dt>
    <dd>语法：<code>drop table 表名;</code></dd>
</dl>

---

<dl>
    <dt>查看数据表</dt>
    <dd>语法：<code>show tables;</code></dd>
    <dd> 查看当前数据库下的所有数据表 </dd>
</dl>

---

<dl>
    <dt>查看数据表结构</dt>
    <dd>语法：<code>desc table 表名;</code></dd>
</dl>

---

<dl>
    <dt>修改数据表</dt>
    <dd>语法：<code>alter table 表名 关键字 修改的内容</code></dd>
</dl>

- add: 添加字段 `alter table 表名 add 字段1 数据类型;`

- rename: 修改数据表名字 `alter table 表名 rename 新表名; `

- change: 改变数据表字段信息 `alter table 表名 change 旧字段 新字段 数据类型;`
  - Eg: 将 name 更改为 rename:  `alter table 表名 change name rename varChar(20);`
  - 即没有做修改的部分也要完整的输出

- drop: 删除字段 `alter table 表名 drop 字段;`

## 操作：数据

<dl>
    <dt>增加数据</dt>
    <dd>语法：<code>insert into 表名(字段1,字段2,...) values(val1, val2, ...);</code></dd>
    <dd>Eg: <code>insert into shangPing(gid, gname, price) value(1, 香皂, 10), (2, 充电器, 20)</code></dd>
</dl>

---

<dl>
    <dt>删除数据信息</dt>
    <dd>语法：<code>delete from 表名 [where 条件]</code>;</dd>
    <dd>Eg: 删除goods表中gid为1的记录 <code>delete from goods where gid=1;</code></dd>
    <dd>如果没有条件，则表示清空所有数据</dd>
</dl>

---

<dl>
    <dt>修改数据信息</dt>
    <dd>语法：<code>update 表名 set 修改的内容1, 修改的内容2 [where 条件];</code></dd>
    <dd>将成绩表里001学员的成绩加2分，注意学号是字符型的。 <code>update xsb set cj=cj+2 where xh='001';</code> </dd>
</dl>

---

<dl>
    <dt>查询数据信息</dt>
    <dd>语法：<code>select *|字段1, 字段2, ... from 表 [where 条件]</code></dd>
    <dd>查询学生表中所有信息 <code>select * from xsb;</code> </dd>
    <dd>查询学生表中所有学号和姓名 <code>select xh, xm from xsb;</code> </dd>
    <dd>查询学生表中所有女生的学号和姓名 <code>select xm, xh from xsb where xb='女';</code> </dd>
</dl>
