切片后，切片本身不会影响源对象

> 若是列表切片，还被赋值了，则会影响源对象

    x = [1, 2, 3, 8]
    print(x) # [1, 2, 3, 8]
    x[1]=3
    print(x) # [1, 3, 3, 8]
    x[2:] = [4]
    print(x) # [1, 3, 4]

> **Q：索引访问与切片访问的区别？**

首先一点要明确，切片是切片，索引访问是索引访问，他们是两个是不一样的

**切片访问时，若切片位置溢出范围**，则**返回**对应数据类型的**空对象**；

**索引访问时，若索引位置溢出范围**，运行时会给出错误信息：**索引超出范围，越界了**
