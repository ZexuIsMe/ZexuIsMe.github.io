**驻留**是一种内存优化技术，核心原理是**对某些符合特定条件的不可变对象（如字符串、整数等），Python 会在内存中只保留一份副本，让多个变量引用用一个对象，而不是创建多个相同的对象**。以达到减少内存占用提高运行效率的目的。

【**针对目标**】不可变对象
若是可变对象，如列表、字典，它们可能被修改，共享会导致不可预期的问题出现；
驻留不是缓存，驻留的对象不会被垃圾挥手，而缓存时临时存储，可能被清理

## 驻留：整数（-5~256）之间的整数

在 [-5, 256] 之间的整数会**默认**启用驻留机制，因为这些小整数在程序中使用频率极高，驻留能显著优化性能。

```python
## test001.py

x = 100
y = 100
print(id(x), id(y))
print("001", x is y)

a = 300
b = 300
print(id(a), id(b))
print("001", a is b)
```

```python
## test002.py

```

## 驻留：字符串

同整数一样，字符串也能有驻留机制，但有一定的规则限制：

1. **纯字母数字以及下划线组成的字符串**
2. **编译时就能确认的字符串字面量，<mark>不是运行时动态生成的</mark>**
3. **长度为0或1的字符串**

超出以上规则的字符串同 test001.py 与 test002.py 超出范围的数字一样，当前文件查看id是一样的，另一个会id变化了。

## 驻留：其他不可变对象

1. 空元组会被驻留
2. **非空元组是否驻留取决于<mark>其元素是否被驻留</mark>**，规则复杂，通常不依赖其驻留特性

## 手动触发驻留

> sys.intern()

【描述】通过该函数可实现手动强制驻留
【参数类型】只接受字符类型 
【参数个数】`def intern(*args, **kwargs):`，即任意个数
【适用场景】需要大量重复使用相同的长字符串（如处理文本时），手动驻留可减少内存占用。

```python
import sys

s1 = "hello, world!"  # 包含逗号和空格，不符合自动驻留规则
s2 = "hello, world!"
print(s1 is s2)  # False（未驻留）

s3 = sys.intern(s1)
s4 = sys.intern(s2)
print(s3 is s4)  # True（手动驻留后，指向同一对象）
```
【验证过程】
》 test001.py 和 test002.py 分别写入该段代码
》 通过导入的方式，将 test002.py 导入 test001.py 文件，运行 test001.py；
利用导入会运行文件这一特点，即可查看是否驻留成功
