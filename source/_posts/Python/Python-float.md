## 浮点型数字 `0.00`，它是可以有`±` 

计算机中浮点数（如 Python 的 float 类型，遵循 IEEE 754 标准）用单独的符号位表示正负，即使数值为 0，符号位也可被设置为负（即 -0.0）。
在 Python 中，-0 会被解析为 -0.0（浮点数），其符号位为负，但数值部分与 0.0 相同。

当直接打印 -0.0 时，Python 会保留其符号位，显示为 -0.0（或简化为 -0）。
这是因为虽然 -0.0 和 0.0 在数值上等价（-0.0 == 0.0 结果为 True），但底层存储的符号位不同，Python 选择如实展示这一特性。

    print(-0.00 == 0.00) True

数值`-0.00` 是数值 `-0.0`
数值`+0.00` 是数值 `0.0`

> **Q：明明就是 0.0，非得整个 -0.0，那么如何解决这个问题呢？** 

解决方法就是**加一个尾巴**，比如这样

    print(-0.0 + 0.000001) # 输出：0.000001

然后再保留需要的小数位，比如保留两位小数：

    print(f"{(-0.0 + 0.000001):.2f}")
    # 输出还是 0.00

## 支持科学计数法

    # 格式
    mE(e)n

- m 表示底数
- n 表示指数
- mEn=m*10 的n次方

Eg:

    print(-2e3) # -2000.00 》 -2*10*10*10
    print(-2e-3) # - 0.002 》 -2*0.1*0.1*0.1
