## 中位数

将一组数组按大小顺序排列后，位于中间位置的数值，它能反映数据的中等水平，且不收极端值影响

**计算公式**
| 奇偶性 | 起始位                                                         |
|-----|-------------------------------------------------------------|
| 奇数  | **起始位/结束位：(n+1)/2**                                             |
|     | Eg: 数据[1,3,5]，长度为3的奇数，中间位置(3+1)/2，中位数是第二个数：3                |
| 偶数  | **起始位：n/2**                                                    |
|     | **结束位：n/2+1**                                                   |
|     | Eg: 数据[1,3,5,7]，长度为4的偶数，那么起始位 4/2=2，结束位为 4/2+1=3，对应中位数数值分别是3和5 |

## 直通率

是指产品一次性通过检验的比率,属于生产过程中的质量指标,不是可靠性指标。直通率反映的是生产过程的能力,而不是产品本身的可靠性特征
