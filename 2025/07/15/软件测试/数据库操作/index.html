数据类型：数字

  • int：int(11)

    • type: 整型
    • 11：表示 int 类型最大值，其取值区间为 [1, 11]

  • float：float(m, d)

    • type: 单精度浮点型
    • m：表示长度或者位数
    • d：表示小数位数（小数位数是算在长度内的）
    • Eg: float(6, 2)：表示该浮点数最大长度位6，且有两位小数，整数长度为 m-d, 即 4 位
    • 若长度超出6，如 12345，则不会被允许添加

  • double：double(m, d)

    • type: 双精度浮点型

    • m、d 同 float 一样

    • Q：单精度与双精度有什么区别？

      能定义的长度不同，单精度为4个字节（7位有效数），双精度为8个字节（16位有效数）

  • decimal: decimal(m, d)

    • type: 定点型

    • m、d 同 float 一样

    • Q：浮点型与定点型的区别？

      浮点型是近似值数据类型，存在误差，如 10/3 ≈ 3.33333 在数据库中可能是 3.33335。

      定点型以字符串的形式存储数据，解决了浮点型带来的误差问题。

      故，如果对数据的完整度十分敏感，那么采用定点型数据类型是合适的。

数据类型：字符

  • char: char(m)

    • type: 字符串
    • m：表示字符串的长度
    • 一种固定了长度的，如果字符不够，则会用空格替代的字符串数据类型
    • 如一个长度为5的 char 字段，要写入 ‘汉字’ > ‘汉字xxx’（x 在这里表示空格占位）
    • 同 int 一样，若超出长度，则无法写入

  • varchar: varchar(m)

    • type: 字符串

    • m：表示字符串的长度

    • 不固定长度的字符串数据类型

    • 如一个长度为5的 varchar 字段，要写入 ‘汉字’ > ‘汉字2’；其中2表示该字符的长度

    • 同 int 一样，若超出长度，则无法写入

    • Q：char 与 varchar 的区别？

      char是固定长度的，可以有更快的读取速度，如固定长度的身份证之类的
      varchar 是不固定长度的，相对于 char 而言，节约开销，比如名字，就适合用 varchar

  • enmu: enmu('1', '2', ...)

    • type: 枚举型
    • 设置字段的取值范围

数据类型：日期

  • date: 日期型，结构为 YYYY-MM-DD
  • time: 时间型，结构为 HH-mm-ss
  • datetime: 日期时间型，结构为 YYY-MM-DD HH-mm-ss
  • timestamp: 时间戳，结构为YYYYMMDDHHmmss
  • year: 年
  • …月，日，

操作：数据库

添加数据库
语法：create database 数据库库名;
删除数据库
语法：drop database 数据库库名;
查看数据库
语法：show databases;
使用数据库
语法：use 数据库库名;

操作：数据表

添加一个表
语法：create table 表名(字段1 数据类型, 字段2 数据类型);
Eg: create table student(id int, sname varchar(20));
删除数据表
语法：drop table 表名;
查看数据表
语法：show tables;
查看当前数据库下的所有数据表
查看数据表结构
语法：desc table 表名;
修改数据表
语法：alter table 表名 关键字 修改的内容

  • add: 添加字段 alter table 表名 add 字段1 数据类型;

  • rename: 修改数据表名字 alter table 表名 rename 新表名;

  • change: 改变数据表字段信息 alter table 表名 change 旧字段 新字段 数据类型;

    • Eg: 将 name 更改为 rename: alter table 表名 change name rename varChar(20);
    • 即没有做修改的部分也要完整的输出

  • drop: 删除字段 alter table 表名 drop 字段;

操作：数据

增加数据
语法：insert into 表名(字段1,字段2,...) values(val1, val2, ...);
Eg: insert into shangPing(gid, gname, price) value(1, 香皂, 10), (2, 充电器, 20)
删除数据信息
语法：delete from 表名 [where 条件];
Eg: 删除goods表中gid为1的记录 delete from goods where gid=1;
如果没有条件，则表示清空所有数据
修改数据信息
语法：update 表名 set 修改的内容1, 修改的内容2 [where 条件];
将成绩表里001学员的成绩加2分，注意学号是字符型的。 update xsb set cj=cj+2 where xh='001';
查询数据信息
语法：select *|字段1, 字段2, ... from 表 [where 条件]
查询学生表中所有信息 select * from xsb;
查询学生表中所有学号和姓名 select xh, xm from xsb;
查询学生表中所有女生的学号和姓名 select xm, xh from xsb where xb='女';
